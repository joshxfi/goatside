# Security

Goatside holds people's own financial records, so security reports are welcome and
taken seriously.

## Reporting a vulnerability

Report it privately through **Security → Report a vulnerability** on
[the GitHub repo](https://github.com/joshxfi/goatside/security). Please don't open a
public issue.

Include what's affected, how to reproduce it, and what an attacker could do with it.
You'll get a reply within a week.

## Supported versions

Goatside is self-hosted and updated by syncing your fork. Fixes land on `main`, so keep
your deploy up to date. See
[Updating](apps/web/content/docs/self-hosting/updating.mdx).
